# 综合测试归档（comprehensiveTest）

> 归档日期：2026-06-14  
> 场景：`StartGame` → `PoolTest`  
> 验证：**GameEventBus**、**PrefabPool** / `PrefabPoolManager.GetOrCreatPool`、玩家生命与复活、日志导出、**池所有权（谁创建谁销毁）**

### 池所有权约定（无全局 PoolHost）

| 组件 | 职责 |
|------|------|
| `PlayerTest` | 首次射击 `GetOrCreatPool` 子弹池；`OnDestroy` 对称 `ReleasePoolShare` |
| `enemyManager` | 只刷怪（`GetObj` / `Instantiate`），**不引用** `enemyTest`；Pooled 时建敌人池 `Model/Prefabs/enemy` |
| `enemyTest` | 预制体 `OnEnable` 自初始化；各实例建子弹池份额；**Direct** 死亡 `Destroy`→`OnDestroy` 卸份额；**Pooled** 死亡 `RecycleObj` 不卸子弹份额 |
| `ComprehensiveTestSceneFlow` | 切场景 / ExitGame 前 `CleanupBeforeSceneChange()` |

### 敌人生成模式（`ComprehensiveTestDebugConfig`）

挂载在 `PoolTest` → `ComprehensiveTestRoot`，Inspector 切换：

| 模式 | 行为 | 子弹 ref 随敌人死亡 |
|------|------|---------------------|
| **DirectInstantiate**（默认） | `Load` + `Instantiate`，死亡 `Destroy` | **会降**（`OnDestroy` 卸份额） |
| **Pooled** | 敌人 `PrefabPool` Get/Release | **不降**（回敌人池不 Destroy） |

### Logger 池快照字段（`ComprehensiveTestLogger`）

| 字段 | 含义 | 本场景预期 |
|------|------|------------|
| `b` | `PrefabPool.ActiveCount`（已借出未归还） | 战斗波动 |
| `p` | `PrefabPool.InactiveCount`（闲置队列深度） | 子弹寿命后回升 |
| `池ref[…]` | 即时打点（建池/死亡/生成等） | `ref` 应在 `GetOrCreatPool` 时 +1、`OnDestroy` 时 -1 |
| 周期行 `池 Bullet … ref=… holders=…` | 每 5s 快照 | 需 `schema=v2-ref-holders-max` |
| `max` | `MaxInactiveCapacity`（`48 × ref`） | 随 `ref` 倍增 |
| `ch` | `PoolRuntime` 下 `Pool_*` 子节点数 | 两池存在时为 **2** |
| `rootInActive` | `PoolRuntime` 是否归属当前 Active Scene | **true** |
| `池校验` | Hierarchy `activeSelf` 子节点数 vs 池 `b/p` 不一致 | 不应出现 |
| `ref异常` / `max异常` | 与上表预期不符 | 不应出现 |
| `池未注册` | 尚未 `GetOrCreatPool`（子弹池在首次射击前正常） | — |
