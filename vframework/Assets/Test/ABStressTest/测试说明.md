# ABStressTest 混载压测说明

> 路径：`Assets/Test/ABStressTest/`  
> 场景：`ABStressTest.unity`（**不加入** Build Settings；Editor Play 即可）  
> 与 [AB_Test 集成测试](../AB_Test/集成测试归档.md) **隔离**，不污染 `ConcurrentLoad_*` / `UniConcurrentLoad_*` 门禁。

---

## 1. 用途

多 Worker **模板实例化并发**，按 Profile 混用 `Load<T>` 与 `LoadUniTaskAsync<T>`，验证：

- 多路同时加载 / Release、Ref、Bundle LRU
- **Safe**：各 Worker 分 path，期望 `failCount=0`
- **Boundary**：故意 sync/async 撞同 path，记录行为（**非回归门禁**）

---

## 2. 场景层级

```text
ABStressTestRoot
├── LoadApiTestLogCollector
├── ABStressOrchestrator          # 生成 Worker、等齐、UnloadAll
└── ABStressWorkerTemplate        # Inactive，仅含 ABStressWorker（勿启用）
```

Play 后运行时：

```text
ABStressTestRoot
├── ABStressWorker_0 … _N-1         # 由 Orchestrator Instantiate 模板生成
└── ABStressWorkerTemplate        # 仍为 Inactive 模板
```

**勿**再使用「复制整颗 Root」方式：会在 `Instantiate` 时触发克隆体 `Awake`，造成指数级嵌套与 Editor 卡死。

| 节点 | 组件 |
|------|------|
| `ABStressTestRoot` | `LoadApiTestLogCollector` + `ABStressOrchestrator` |
| `ABStressWorkerTemplate` | `ABStressWorker`（**默认 Inactive**） |
| `Canvas/Log` | Collector 的 `logText` |
| `Canvas/EndAndLog` | `ForceEndSession` |

**Collector 运行时**（由 Orchestrator 设置）：

| 字段 | 值 |
|------|-----|
| `sessionIdPrefix` | `ABStressLoad_` |
| `expectedConcurrentRunners` | `workerCount + 1`（含 Orchestrator 收尾） |
| `unloadAllRunnerSource` | `ABStressOrchestrator` |

---

## 3. ABStressOrchestrator Inspector

| 字段 | 说明 |
|------|------|
| `workerCount` | 并行 Worker 数量 |
| `workerTemplate` | Inactive 子节点 `ABStressWorkerTemplate` |
| `stressProfile` | `Safe` / `Boundary` |
| `waves` | 每 Worker 波次数 |
| `pathsPerWave` | Catalogue 简路径 |
| `staggerFrames` | 错开帧数；Boundary 建议 `0` |
| `releaseAfterEachLoad` | 每轮 `Release` |

### Worker 模式（`workerIndex % 3`）

| Index | Safe | Boundary |
|-------|------|----------|
| 0 | 同步 `Load` | 同步 `Load`（与 Worker1 同 path） |
| 1 | `LoadUniTaskAsync` | `LoadUniTaskAsync`（与 Worker0 同 path） |
| 2 | 波次交替 Sync/Async | 同 path 先 Sync 再 Async |

---

## 4. 日志与验收

**输出：** `StreamingAssets/{平台}/Logs/ABStressLoad_*.json`

| Profile | 期望 |
|---------|------|
| **Safe** | `failCount=0`；`completedRunners` 含 `ABStressWorker_0..N-1` 与 `ABStressOrchestrator` |
| **Boundary** | 允许 `failCount>0`；不得卡死 |

`passCount` 约 `workerCount × waves` + 1 条 `UnloadAll`。

---

## 5. 操作步骤

1. 打开 `ABStressTest.unity`
2. 确认 `ABStressWorkerTemplate` 为 **Inactive**
3. `stressProfile = Safe`，Play
4. Hierarchy 应仅多出 `workerCount` 个 Worker，无爆炸式节点
5. 查看 `ABStressLoad_*.json`
