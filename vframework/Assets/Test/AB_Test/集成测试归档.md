## 1. 测试套系总览（先看这里）

|------|----------|----------|----------|----------|----------------|-----------|
| **同步并发** ★ | `Myloadtest`（9 Case） | `MyLoadTest2`（8 Case） | `Load<T>()` | **已启用** | **19** | `ConcurrentLoad_` |
| **异步并发** | `MyLoadUniTest`（10 Case） | `MyLoadUniTest2`（9 Case） | `LoadUniTaskAsync<T>()` | **已禁用** | **21** | `UniConcurrentLoad_` |

| **依赖拓扑** | `MyDependencyTest`（3 Case） | — | `GetBundleDependencies` + 跨包 UI Load | **已禁用** | **1~3** | `DependencyLoad_` |
| **CDN 热更** | `MyCdnHotUpdateTest`（5 Case） | — | Init / cache / catalogueHash / cdnBaseUrl | **已禁用** | **1~5** | `MyCdnHotUpdateTest_` |
| **Stress 压力** | `MyLoadStressTest`（4 Case） | — | 快速 Load/Release | **已禁用** | **4** | `StressLoad_` |

**并发测什么？**

- **有。** 默认跑的就是 **双 Runner 同步并发**：两脚本同时 Start，交错 Case，共享同一 Prefab/Atlas/UI 路径，验证 **缓存命中、Ref++、多 bundle 并存、UnloadAll 独占**。
- 三端基准见 §6（`001824` / `004641` Editor，`004530` Player，`004612` Android）。

**LoadUniTaskAsync 呢？**

| 层级 | 状态 |
|------|------|
| **框架 API** | ✅ `LoadUniTaskAsync` + `ResourceLoadCoordinator`（真异步 I/O、TCS inFlight 合并） |
| **集成脚本** | ✅ `MyLoadUniTest`（10 Case）+ `MyLoadUniTest2`（9 Case）；含 **InflightAbandon** / **InflightParallel** |
| **归档 JSON（B-1）** | ✅ 三端 `UniConcurrentLoad_*` **19/0**（`225805` / `230136` / `231720`） |
| **归档 JSON（B-2）** | ✅ **Editor 21/0**（`215550`，2026-06-17）；Player / Android 待跑 |

详见 [LoaderDesignGuide.md](../../vFramework/BaseFramework/BaseAssetSys/ResLoader/LoaderDesignGuide.md)、[BusinessApiAndCdnPlanning.md](../../vFramework/BaseFramework/BaseAssetSys/Docs/BusinessApiAndCdnPlanning.md)。

## 3. 切换套系（Inspector 操作）

### 跑同步双 Runner（默认，P0 Android / Windows Player）

1. **启用**：`Myloadtest`、`MyLoadTest2`  
2. **禁用**：`MyLoadUniTest`、`MyLoadUniTest2`  
3. Collector：`sessionIdPrefix=ConcurrentLoad_`，`unloadAllRunnerSource=Myloadtest`  
4. Play → 等 ~3～4 分钟 → 验收 `ConcurrentLoad_*.json`

### 跑异步双 Runner（LoadUniTaskAsync 集成）

1. **禁用**：`Myloadtest`、`MyLoadTest2`  
2. **启用**：`MyLoadUniTest`、`MyLoadUniTest2`  
3. Collector：`sessionIdPrefix=UniConcurrentLoad_`，`unloadAllRunnerSource=MyLoadUniTest`  
4. Play → 验收 `UniConcurrentLoad_*.json`，`passCount=21`

**切勿多套 Runner 同时启用**（会变成多 Runner 抢同一资源，结果无效）。  
例外：Stress 三 Runner 扩展见 [测试说明.md §5](./测试说明.md)。

### 跑 Router 套系（AssetRouter 四源）

1. **禁用**：`Myloadtest`、`MyLoadTest2`、`MyLoadUniTest*`、`MyLoadStressTest`  
2. **启用**：`MyRouterTest`  
3. Collector：`sessionIdPrefix=RouterLoad_`，`expectedConcurrentRunners=1`  
4. Play → 验收 `RouterLoad_*.json`，`failCount=0`

### 跑依赖拓扑套系（`MyDependencyTest`）

1. **前置**：Packer 以 **首包（真机模式）** 打包一次，确保 `catalog.bytes` 的 `bundles[]` 非空  
2. **禁用**：其余 Runner  
3. **启用**：`MyDependencyTest`  
4. Collector：`sessionIdPrefix=DependencyLoad_`，`expectedConcurrentRunners=1`  
5. Play → 验收 `DependencyLoad_*.json`（Case 0/1 验拓扑；Case 2 Load `UI/TestUI`）

### 跑 CDN 热更套系（`MyCdnHotUpdateTest`）

1. **前置**：DeviceDebug 或 CdnHotUpdate 打包；清单含 `catalogueHash`；下载验证需配置 `BuildSetting.cdnBaseUrl` 并重打包  
2. **禁用**：其余 Runner  
3. **启用**：`MyCdnHotUpdateTest`  
4. Collector：`sessionIdPrefix=MyCdnHotUpdateTest_`，`expectedConcurrentRunners=1`  
5. Play → 验收 `MyCdnHotUpdateTest_*.json`（Case 0~4 验 Init / ABCache / hash / cdnBaseUrl）

**构建报告路径**（打包后）：`{bundleRoot}/Reports/BundleBuildReport.json`（Packer 窗口「上次构建报告」可预览）

### 跑 Stress 套系

1. **禁用**其余 Runner，**启用** `MyLoadStressTest`  
2. Collector：`sessionIdPrefix=StressLoad_`，`expectedConcurrentRunners=1`，`unloadAllRunnerSource=MyLoadStressTest`  
3. 可调 Inspector `stressCycles`（默认 20）

## 5. Case 明细

### 5.1 同步 — Myloadtest（9 Case）

| Case | API | 说明 |
|------|-----|------|
| 0 | Catalogue | `EnsureReady()` |
| 1 | Load Prefab | `Load<GameObject>` + Instantiate |
| 2 | Apply Sprite | Icon/3 → 材质 |
| 3 | Replace Material | ReplaceMat |
| 4 | Cross Atlas | 与 model 并存 |
| 5 | Cross UI | Instantiate UIRoot |
| 6 | Release | 释放辅助资源 |
| 7 | Destroy Prefab | Destroy + Release prefab |
| 8 | UnloadAll | 等 MyLoadTest2 → Verify → UnloadAll |

### 5.2 同步 — MyLoadTest2（8 Case）

| Case | API | 说明 |
|------|-----|------|
| 0 | Catalogue | 并行 EnsureReady |
| 1 | Load Prefab | 并发 Load + Instantiate |
| 2 | ReLoad Prefab | cache hit + ref++ |
| 3 | Load Sprite | Icon/3 |
| 4 | Cross Atlas | 并发 atlas |
| 5 | Cross UI | 并发 ui |
| 6 | Release | 保留 prefab 句柄 |
| 7 | Verify Chain | 探针；不 UnloadAll |

### 5.3 异步 — MyLoadUniTest（10 Case）/ MyLoadUniTest2（9 Case）

Case 0～7 与同步套系对齐，Load 全部改为 **`LoadUniTaskAsync<T>()`**。

| Runner | Case | API | B-2 增量说明 |
|--------|------|-----|----------------|
| `MyLoadUniTest` | 8 | **InflightAbandon** | `VerifyInflightAbandonAsync`（`Icon/3`）；加载中 Release → ref==0 不入缓存 |
| `MyLoadUniTest` | 9 | UnloadAll | 原 Case 8 顺延；等 peer → Verify → UnloadAll |
| `MyLoadUniTest2` | 8 | **InflightParallel** | `UniTask.WhenAll` 两次 `LoadUniTaskAsync` 同 path（`Model/Prefabs/tester`） |
| `MyLoadUniTest2` | — | （无 Case 9） | 9 Case 结束即 `NotifyRunnerComplete` |

**Case 8 路径约定：** Runner A 用 `Icon/3`、Runner B 用 `tester`，避免双 Runner 同 round 抢同一 resource key。

## 7. Player 打包复现（P0-1 / P0-2）

1. Packer 打对应平台 **DeviceDebug** AB

## 8. 关键约定

- **UnloadAll**：进程级 shutdown；同步仅 `Myloadtest`、异步仅 `MyLoadUniTest`  
- **Android Catalogue**：`jar:` 路径走 `StreamingAssetsIO`  
- **Catalogue `bundles[]`**：已有 bundle 列表；`dependencies` 多为空，依赖预加载 Case 未覆盖  
- **LoadUniTaskAsync 实现阶段**：B-2 真异步 I/O + `ResourceLoadCoordinator` / `BundleManager` TCS inFlight；加载中 Release 不 Unload，完成时 ref==0 丢弃
