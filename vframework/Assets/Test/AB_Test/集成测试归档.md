# AB 集成测试归档（DeviceDebug + Myloadtest）

> 归档日期：2026-06-10（更新：9 Case 跨包版）  
> 状态：**Editor / Windows Player 9/9 PASS**

---

## 1. 目标

在 **DeviceDebug + StandaloneWindows64** 产物上，验证 `BundleResLoader` 同步加载链路：

1. 加载 Prefab 并 `Instantiate`
2. 对**首个实例**换贴图、换材质
3. **多 bundle 并存**（model + icon + atlas + ui）
4. 释放辅助资源、销毁实例、`UnloadAll`

---

## 4. 测试流程（9 Case）

| Case | API | 说明 |
|------|-----|------|
| 0 | Catalogue | `EnsureReady()`，确认 bundle 根目录 |
| 1 | Load Prefab | `Load<GameObject>` + `Instantiate()` → tester |
| 2 | Apply Sprite | `Icon/3` → 实例材质 `_BaseMap` / `mainTexture` |
| 3 | Replace Material | `ReplaceMat` 替换 `renderer.material` |
| 4 | Cross Atlas | `Atlas/Role/Hog_Attack_000`（model 仍占用） |
| 5 | Cross UI | `UI/UIRoot` 加载并 `Instantiate` |
| 6 | Release | Release sprite / material / atlas / ui |
| 7 | Destroy Prefab | Destroy tester + Release prefab AB |
| 8 | Finish | `BundleResLoader.UnloadAll()` |

- Case 0→1 **无间隔**；Case 2～8 间隔 `intervalSeconds`（默认 **5s**），全流程约 **40s**
- **ExitBtn** → `FinishTestAndSaveLog()`（写 JSON，可选退出）
- **BtnLoad** → `LoadPrefabNow()`（仅 Case 1）

## 7. 复现步骤

1. **DeviceDebug + Windows** 打包（`StreamingAssets/StandaloneWindows64/` 含 model/icon/atlas/ui 等 `.bundle` + Catalogue）
2. 打开 `TestABScene`，Editor Play 或打 Windows 包
3. 等待 **Case 0～8** 跑完（约 40s），或点 ExitBtn 提前保存
4. 验收：`failCount == 0`，`passCount == 9`，entries 含 Cross Atlas / Cross UI

---

## 8. 关键约定

- Prefab：Load 后 `Instantiate()`，勿在实例化前多余 `Release prefabRes`
- 贴图：URP 写 `_BaseMap` + `mainTexture`；Sprite 用 `Load<Sprite>` 取 `.texture`
- bundle 名：构建与运行时统一 **小写**（如 `icon.bundle`、`atlas.bundle`）
- 跨包：Case 4/5 在 model 仍占用时加载 atlas/ui，验证多 bundle 并存
- **未覆盖**：Catalogue `bundles[].dependencies` 自动依赖预加载（清单 `bundles` 当前为空）
