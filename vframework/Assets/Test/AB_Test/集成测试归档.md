# AB 集成测试归档（DeviceDebug + Myloadtest）

> 归档日期：2026-06-10  
> 状态：**Editor / Windows Player 7/7 PASS**

---

## 1. 目标

在 **DeviceDebug + StandaloneWindows64** 产物上，验证 `BundleResLoader` 同步加载链路：

1. 加载 Prefab 并 `Instantiate`
2. 对**首个实例**换贴图、换材质
3. 释放辅助资源、销毁实例、`UnloadAll`

---

## 2. 脚本与场景

| 文件 | 作用 |
|------|------|
| `Assets/Test/AB_Test/Myloadtest.cs` | 7 步集成测试主脚本 |
| `Assets/Test/AB_Test/LoadApiTestLogCollector.cs` | JSON + ShowLog UI 日志 |
| `Assets/Test/AB_Test_Target/TestABScene.unity` | 测试场景（`ABundleTestRunner`） |

**已删除：** `LoadApiTester.cs`（逻辑过重，已由 `Myloadtest` 替代）

**参考写法：** `Myloadtest` 与最小示例一致 — `Load<T>()` → `Instantiate()` / `GetAsset<T>()`。

---

## 4. 测试流程（9 Case）

| Case | API | 说明 |
|------|-----|------|
| 0 | Catalogue | `EnsureReady()`，确认 bundle 根目录 |
| 1 | Load Prefab | `Load<GameObject>` + `Instantiate()` |
| 2 | Apply Sprite | `Icon/3` → 实例材质 `_BaseMap` / `mainTexture` |
| 3 | Replace Material | `ReplaceMat` 替换 `renderer.material` |
| 4 | Cross Atlas | `Atlas/Role/Hog_Attack_000`（`atlas.bundle`，model 仍占用） |
| 5 | Cross UI | `UI/UIRoot`（`ui.bundle`） |
| 6 | Release | Release sprite / material / atlas / ui |
| 7 | Destroy Prefab | Destroy 实例 + Release prefab AB |
| 8 | Finish | `BundleResLoader.UnloadAll()` |

- 默认 **Case 0 与 Case 1 连续执行**，Case 2～8 间隔 `intervalSeconds`（默认 5s）
- **ExitBtn** → `FinishTestAndSaveLog()`（写 JSON，可选退出）
- **BtnLoad** → `LoadPrefabNow()`（仅 Case 1）

## 5. 日志输出

`LoadApiTestLogCollector.useBundleRootForLogs = true` 时，JSON 写在 **AB 运行时根目录下的 `Logs/`**：

| 环境 | 路径 |
|------|------|
| Editor Play | `Assets/StreamingAssets/StandaloneWindows64/Logs/` |
| Windows 打包 | `{exe}_Data/StreamingAssets/StandaloneWindows64/Logs/` |
| Android（包内不可写时） | 回退 `persistentDataPath/AB_Test/Logs/` |

ShowLog Text 实时显示同内容；文件名：`Myloadtest_yyyyMMdd_HHmmss.json`。

## 7. 运行步骤（复现）

1. **DeviceDebug + Windows** 打包（生成 `StreamingAssets/StandaloneWindows64/*.bundle` + Catalogue）
2. 打开 `TestABScene`，Play 或打 Windows 包
3. 等待 Case 0～6 自动跑完（约 30s），或点 ExitBtn 提前结束并保存
4. 检查 JSON：`failCount == 0`，且 entries 含 Case 0～6

---

## 8. 关键实现约定

- Prefab：**不要**在 `Instantiate` 前对 `prefabRes` 做多余 `Release`
- 贴图：URP Lit 写 `_BaseMap` + `mainTexture`；Sprite 用 `Load<Sprite>` 取 `.texture`
- bundle 名：构建与运行时统一 **小写** `.bundle`（如 `icon.bundle`、`model.bundle`）
- 实例 Destroy 与 `AbstractResource.Release()` 分离（设计文档 § AbstractResource）
