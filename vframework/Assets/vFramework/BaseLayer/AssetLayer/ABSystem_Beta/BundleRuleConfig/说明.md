# BundleRuleConfig 模块说明

> 路径：`ABSystem_Beta/BundleRuleConfig/`  
> 打包规则持久化 + 清单数据结构（**非** Editor 专用）。

---

## 子目录

| 目录 | 内容 |
|------|------|
| `Setting/` | `BuildSetting.cs`、`DefaultBuildSetting.asset`、`BundlePlatformPaths.cs` |
| `Catalogue/` | `AssetCatalog.cs`、`AssetCatalog.json` — 清单 schema 与工程内副本 |

---

## BuildSetting 要点

| 字段 | 默认 | 说明 |
|------|------|------|
| `deviceOutputPath` | `Assets/StreamingAssets` | 首包（真机模式）**根路径** |
| `cdnOutputPath` | `Bundles/CDN` | CDN 模式 **根路径** |
| `usePlatformSubfolders` | `true` | 在根路径下追加 `{平台}/`，如 `StandaloneWindows64`、`Android` |
| `buildMode` | `DeviceDebug` | 全局打包模式（Custom 时每项可覆盖） |
| `version` / `buildNumber` | — | 写入清单，供 **热更 / CDN 版本对比**（加载侧 TODO） |

**自定义配置项 `BundleConfigItem`：**

| 字段 | 说明 |
|------|------|
| `assetPath` | 文件夹或单文件路径 |
| `folderPackingRule` | 文件夹粒度：`EntireFolder` / `FirstLevelSubfolders` / `AllSubfolders`（与全局 Default/Detailed 语义一致） |
| `bundleName` | 「整个文件夹一个包」或单文件时使用；子文件夹粒度下由文件夹名自动生成 |
| `buildMode` | 该项 AB 输出到首包或 CDN 等 |
| `downloadPriority` | 热更优先级标记（运行时 TODO） |

---

## AssetCatalog 要点

- `entries[]`：资源路径 → bundle + assetName  
- `bundles[]`：bundle → 依赖 bundle 列表（打包时从 Manifest 写入）  
- 运行时读取副本：`{bundleRoot}/Catalogue/AssetCatalog.json`

详见 [Docs/Catalogue清单说明.md](../Docs/Catalogue清单说明.md)。

## 实际输出示例（`usePlatformSubfolders = true`）

| 平台 | 首包（DeviceDebug） | CDN（CdnHotUpdate） |
|------|---------------------|---------------------|
| Windows | `Assets/StreamingAssets/StandaloneWindows64/` | `Bundles/CDN/StandaloneWindows64/` |
| Android | `Assets/StreamingAssets/Android/` | `Bundles/CDN/Android/` |

Win / Android 可 **同时存在** 于同一工程中，互不覆盖（便于 Editor 联调、多端 AB 增量构建）。

**Player 打包：** Unity 默认会把整个 `Assets/StreamingAssets/` 打进包体。`Editor/StreamingAssetsPlatformBuildFilter` 在 **Build Player 前**临时移出非目标平台子目录（如打 Windows 时移出 `Android/`），构建结束后自动还原，避免 Win 包带 Android AB、APK 带 Windows AB。AB 打包器「开始打包」仍只写当前 `BuildSetting.platform` 对应目录，与此过滤互补。

运行时：`Init(null)` → `StreamingAssets/{当前平台}/`（见 `BundlePlatformPaths`）；支持同步 `Load("Atlas/Role/资源名")` 与 UniTask 异步 `LoadUniTaskAsync("Atlas/Role/资源名")`。

- **CdnHotUpdate** 模式将 AB 打到 `cdnOutputPath`；运维/CI 上传至 CDN。  
- 运行时 **不** 读本目录下的 JSON；读缓存或 StreamingAssets 下的 Catalogue。  
- 远程清单 URL、hash 等 **未** 纳入 BuildSetting，见 [Docs/业务API与CDN规划.md](../Docs/业务API与CDN规划.md)。
