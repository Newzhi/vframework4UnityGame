## 阅读顺序建议

1. **设计目标与实现细节** → 知道整体目标与当前进度  
2. **业务API与CDN规划** → 知道业务 API 与 CDN 怎么接  
3. **Catalogue清单说明** + **加载器设计说明** → 打通加载链路  
4. **Editor / BundleRuleConfig 说明** → 打包与配置  
5. **测试用例** → 验收  
6. **集成测试归档**（`Assets/Test/AB_Test/`）→ DeviceDebug + Myloadtest 7 Case 验收与日志约定

- CDN、异步、路由器等跨模块内容：细节放 **ResLoader/说明**，原则与路线图放 **Docs/业务API与CDN规划.md**。
