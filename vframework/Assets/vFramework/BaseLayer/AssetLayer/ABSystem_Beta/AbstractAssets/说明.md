# AbstractAssets 模块说明

> 路径：`ABSystem_Beta/AbstractAssets/`  
> 核心类：`AbstractResource.cs`

---

## 职责

- 封装 **单个 AB 内资源** 的加载结果与 **Resource 层引用计数**。
- 业务 **不** 直接 `AssetBundle.LoadAsset` / `Unload`；通过 `AbstractResource` + `Release()` 与 `BundleManager` 联动。

---

## 引用计数

| 操作 | 行为 |
|------|------|
| `Load` 命中缓存 | `AddReference()`，Ref+1 |
| `Release()` | Ref-1；Ref=0 时 `UnLoad()` |
| `UnLoad()` | 清空 asset 引用、`ReleaseBundle`、触发 `onUnLoad` 回调 |

`onUnLoad` 由 `BundleResLoader` 注册，用于从 `resourceDic` 移除缓存项（见加载器说明 §4）。

---

## 业务 API 对应

| 设计基线需求 | 本模块 |
|--------------|--------|
| §5 卸载单个资源 | ✅ `Release()` |
| §5 Instantiate | ✅ `Instantiate()`（实例 Destroy 与 Release 无关） |

---

## 已知限制

- `UnLoad` 仅 `ReleaseBundle` **主包**；依赖包 Ref 由 `AcquireBundleWithDependencies` 增加，**暂未**随主资源 Release 递减（见测试 L-022）。
