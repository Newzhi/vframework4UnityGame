# Editor 打包模块说明

> 路径：`ABSystem_Beta/Editor/`  
> 菜单：**vFramework → AssetBundle Packer**

---

## 子模块

| 目录 | 类 | 职责 |
|------|-----|------|
| `BundleRuleMaker/` | `BundleRuleMaker` | 规则编辑 UI（View）、Save 配置 |
| `BundleBuilder/` | `BundleBuilder` | Build / Clean / Validate；输出 `{根}/{平台}/` |
| `BundleRuleConfig/BundlePlatformPaths.cs` | 平台子目录名（与 Runtime 共用） |
| `BundleBuilder/` | `RuleResolver` | Default / Detailed / Custom → `AssetBundleBuild[]` |
| `BundleBuilder/` | `CatalogueWriter` | 写 `AssetCatalog.json`（含 `bundles[]`） |
| `BundleAnyazier/` | `BundleAnyazier` | 占位，打包后分析未实现 |

---

## 打包模式与输出

| 模式 | AB | 清单 |
|------|-----|------|
| EditorTest | 不打 AB | 写 JSON（`bundles` 空数组） |
| DeviceDebug | `deviceOutputPath` | 双份 JSON |
| CdnHotUpdate | `cdnOutputPath` | 双份 JSON |
| DlcPackage | 临时同 CDN + Warning | 双份 JSON |

---

## 与 CDN 的关系（打包侧）

- **CdnHotUpdate** 仅决定 **构建输出目录**（默认 `Bundles/CDN`）。  
- **不包含** 上传 CDN、生成下载 URL、运行时下载 — 见 [Docs/业务API与CDN规划.md](../Docs/业务API与CDN规划.md)。
