# 配表工具生成契约（vFramework）

> ExcelTool 与 Unity 工程之间的**固定约定**。路径、程序集、bundle 名变更须同步本文与 `ExcelTool4UnityGame/配置表方案报告.md`。

---

## 1. 固定路径

| 用途 | Unity 路径 | export-config 字段 |
|------|------------|---------------------|
| Excel 源表 | 工具工程外（如 `ExcelTool4UnityGame/TestExcels/`） | `excelRoot` |
| Meta + Table | `Assets/HotUpdateScripts/MetaConfigs/Metas/` | `codeOutput` |
| GameConfigTables | `Assets/HotUpdateScripts/MetaConfigs/` | `globalOutput` |
| 二进制 bytes | **`Assets/AssetBundle/ConfigTables/`**（目录名固定） | `dataOutput` |

示例（相对 `ExcelTool/export-config.json`）：

```json
{
  "codeOutput": "../../vframework/Assets/HotUpdateScripts/MetaConfigs/Metas",
  "globalOutput": "../../vframework/Assets/HotUpdateScripts/MetaConfigs",
  "dataOutput": "../../vframework/Assets/AssetBundle/ConfigTables",
  "namespace": "Game.Config"
}
```

---

## 2. 程序集边界

| 内容 | 程序集 | 是否自动生成 |
|------|--------|--------------|
| `*Meta.cs` / `*Table.cs` / `GameConfigTables.cs` | `HotUpdateScripts` | 是，禁止手改；**C# 8 语法**；`GameConfigTables` 内含 `RegisterToFramework` |
| `XtblBinaryReader` / `BinaryTypeIds` | `BaseLayer` → `GameUtils/BinaryUtils` | 否，手写固定 |
| `ConfigTableModule` / `ConfigTableBytesLoader` / `IConfigTableService` | `BaseLayer` → `ConfigTableLayer` | 否 |
| `ConfigTableInitRegistry` | `BaseLayer` → `ConfigTableLayer` | 否 |

**未导表时**：仓库可无 `GameConfigTables.cs` / `Metas/*.cs`，Unity 仍可编译；`GameBootstrap` 检测到未注册则跳过 `ConfigTableModule`（LogWarning）。

**禁止** BaseLayer 直接引用 `Game.Config` 类型。解析回调由 **导表生成的** `GameConfigTables.RegisterToFramework`（`RuntimeInitializeOnLoadMethod`）注册 `Initialize`。

---

## 3. AssetBundle 打包

- 资源根：`Assets/AssetBundle/`
- 配置表子目录：**`ConfigTables/`**（固定）
- Default 打包规则下 bundle 名：**`configtables.bundle`**
- 运行时 loadPath：`ConfigTables/{表名}`（无扩展名），如 `ConfigTables/Hero`

打包后 catalogue entry 示例：

- `assetPath`: `Assets/AssetBundle/ConfigTables/Hero.bytes`
- `bundleName`: `configtables.bundle`
- `loadPath`: `ConfigTables/Hero`

---

## 4. 运行时两阶段

1. **预加载**：`ConfigTableModule`（Priority 120）→ `ConfigTableBytesLoader` → `BundleResLoader` 加载 `configtables.bundle` 内全部 `TextAsset.bytes`（Editor 无 catalogue 时回退直读 `ConfigTables/` 目录）
2. **解析**：`ConfigTableInitRegistry` 回调 → `GameConfigTables.Initialize(bytesDict)` → 各 `XxxTable` 用 `XtblBinaryReader` 建主键索引

业务查询：

```csharp
var hero = GameConfigTables.Instance.Hero.GetByMainID(10000u);
services.TryGet(out IConfigTableService cfg);
// cfg.IsReady == true 表示上述链路已完成
```

## 5. 导表与验证

```bash
# 在 ExcelTool4UnityGame/ExcelTool 下
dotnet run --project ExcelTool/ExcelTool.csproj -c Debug
# 或双击 export.bat
```

验收：

1. `ConfigTables/*.bytes` 与 `MetaConfigs/**/*.cs` 已更新  
2. AssetBundle Packer 构建后 catalogue 含 `configtables.bundle`  
3. Play + `GameRoot.TryStart(GameBootstrap)` → `GameConfigTables.Instance` 非 null
